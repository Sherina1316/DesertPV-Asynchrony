# v24.22 Novelty-Gated Remote Change Census


## v24.22.2 mixed-pixel parcel addendum

This package adds distributed mixed-pixel parcel reconstruction and a conservative anchor-guided spatial rescue route. It is designed for confirmed 2024 parcels in which every 30 m Landsat cell contains only a fraction of panel rows. The formal direct-training and independent-validation contracts are unchanged. See `MIXED_PIXEL_PARCEL_OPTIMIZATION_V24_22_2_CN.md`. Because Stage 4 quality routing changed, rerun from Stage 4 for the full experiment.

## Purpose

This release distinguishes **newly installed 2025 PV** from dark or structured land parcels that already existed for years. It retains the full-domain remote-site search introduced in v24.21, but no remote object can be accepted solely because it is dark, spatially dense, or PV-like in 2025.

A remote 2025 object must now satisfy two independent contracts:

1. **Terminal state contract**: the 2025 object is sufficiently PV-like and spatially coherent.
2. **Temporal novelty contract**: the object was not already in the same dark/PV-like state before 2025, and the 2024→2025 transition is a dominant recent change.

## 2025 remote-change logic

For every valid pixel outside the frozen 2024 inventory, Stage 7 computes:

- 2025 absolute darkness;
- 2025 PV-state likelihood;
- direct 2024→2025 multiband change;
- robust 2021–2023-to-2025 change;
- terminal state gain relative to 2024;
- dominance of the 2024→2025 break over earlier annual fluctuations;
- pre-existing-state risk;
- prior dark-state persistence;
- persistent non-PV risk;
- object density, geometry, solidity and connected extent.

A remote object is accepted only when a sufficient fraction of its pixels contains genuine terminal-novelty seeds. Weak boundary pixels may be included only when connected to those seeds. A long-standing dark parcel therefore cannot be accepted through object filling or bridge operations.

## Scientific scope

The package retains the complete 21-stage workflow:

- 2011–2025 PV reconstruction;
- bounded refinement of the manually interpreted 2024 reference;
- active versus cumulative PV states;
- installation and retirement timing;
- environmental and ecological analysis;
- PAVG and response-lag analysis;
- Sankey figures;
- strict no-leakage hindcast;
- two-part PV expansion projection to 2050;
- publication maps and reports.

Passing software tests does not establish publication accuracy. Formal accuracy must be assessed using independent historical labels and metrics including precision, recall, IoU, boundary F1, hard-negative false-positive rate, area error and installation-year error.
